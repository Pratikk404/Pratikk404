# 🚀 Featured Project

## [Fundraise Readiness Engine](https://github.com/Pratikk404/FundraiseReadinessEngine)

Document-driven compliance diagnostic for early-stage Indian startups. Founders upload real legal documents (cap tables, incorporation certs, board resolutions), and the system parses, cross-validates, and scores them against regulatory patterns that kill deals during investor diligence.

**Tech:** Java 17, Spring Boot 4.0.1, React 18, Vite 8, Tailwind CSS 4, Node.js 20, Express, BullMQ, PostgreSQL, MongoDB, Redis, Docker, JWT, Maven, OpenAPI/Swagger

| Feature | Details |
|---------|---------|
| Compliance Rules | 5 rules — DilutionSum, DPIIT Recognition, ESOP Consistency, ShareClass, Valuation |
| Tests | 49 unit + integration tests (JUnit 5, Mockito) |
| Document Parser | CSV/XLSX cap table parser (Apache POI) |
| Gap Reports | LLM-powered narrative + printable HTML/PDF export |
| Security | Rate limiting, input sanitization, security headers, CORS |
| Full Stack | Docker Compose (backend + frontend + worker + PostgreSQL + MongoDB + Redis) |
| CI/CD | GitHub Actions (build, test, lint) |
