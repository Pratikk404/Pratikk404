# 🧠 What I Work With

### Backend Architecture
REST API design, JWT authentication, role-based access control, input validation, rate limiting, security headers, CORS configuration, background job processing with message queues.

### Data Layer
Relational schema design (PostgreSQL, MySQL), document stores (MongoDB), caching strategies (Redis), JPA/Hibernate ORM, Spring Data repositories, aggregation pipelines.

### Full-Stack Integration
React dashboards with real-time data, drag-and-drop document uploads, CSV/XLSX parsing, LLM-powered report generation, PDF export, score visualization with charts.

### DevOps & Deployment
Docker multi-stage builds, Docker Compose orchestration, CI/CD pipelines (GitHub Actions), cloud deployment (Railway, Vercel), environment-based configuration.
